About HugoBong

January 1, 2023 · 1 min read

HugoBong is a demonstration of a custom Hugo theme built for simplicity and readability.

It features:

  • Continuous scrolling of full posts.
  • Minimalist design.
  • Dark mode support.
  • Fast loading times.

Built with <3 using Hugo.
