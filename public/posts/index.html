Glassmorphism and Modern aesthetics

October 10, 2023 · 1 min read

You might have noticed the header of this site. It uses a technique called Glassmorphism. This is achieved using CSS backdrop-filter.

header {
    background: rgba(255, 255, 255, 0.8);
    backdrop-filter: blur(12px);
}

It creates a sense of depth and context, allowing the content to gently slide behind the navigation while keeping the menu legible.

Dark Mode Support

This theme also supports dark mode automatically based on your system preferences. The CSS variables handle the switch seamlessly.

  • Backgrounds become dark slate.
  • Text turns into a soft white/blocks.
  • Accents shift to be more luminous.

It’s important to test your designs in both modes to ensure accessibility and visual hierarchy remain intact.

Images in this theme are given a subtle shadow and rounded corners to lift them off the page.

Why Continuous Scroll Works

October 5, 2023 · 1 min read

Pagination is a relic of the past for many types of content. Social media has trained us to scroll. It’s a natural interaction on touch screens and trackpads alike.

Frictionless Reading

By presenting full posts in a stream, we remove the friction of clicking “Read More.” The user can simply glide through the content. If a post catches their eye, they’re already reading it. If not, they scroll past.

This pattern is particularly effective for:

  • Personal blogs
  • News feeds
  • Photo journals
  • Updates and changelogs

Code Syntax Highlighting

Hugo supports syntax highlighting out of the box. Let’s look at a simple Go example since Hugo is built in Go.

package main

import "fmt"

func main() {
    fmt.Println("Hello, Continuous World!")
}

The design of this theme ensures that code blocks are clearly distinct from the text, using a subtle background color and a monospaced font.

The Art of Minimalist Web Design

October 1, 2023 · 2 min read

Minimalism in web design is not just about stripping away elements; it’s about prioritizing content and user experience. When we remove the clutter, we allow the message to shine through.

The Power of Whitespace

Whitespace, or negative space, is one of the most powerful tools in a designer’s arsenal. It dictates the flow of the page, guides the user’s eye, and improves readability.

“Perfection is achieved, not when there is nothing more to add, but when there is nothing left to take away.” - Antoine de Saint-Exupéry

In a continuous scroll layout like this one, whitespace serves as a breath between thoughts. It separates posts without the need for jarring lines or heavy borders.

Typography Matters

When you have fewer elements, the detailed execution of the remaining elements becomes critical. Typography must be impeccable. We’ve chosen Outfit for headings and Inter for body text to ensure maximum legibility and a modern feel.
