Why Continuous Scroll Works

October 5, 2023 · 1 min read

Pagination is a relic of the past for many types of content. Social media has trained us to scroll. It’s a natural interaction on touch screens and trackpads alike.

Frictionless Reading

By presenting full posts in a stream, we remove the friction of clicking “Read More.” The user can simply glide through the content. If a post catches their eye, they’re already reading it. If not, they scroll past.

This pattern is particularly effective for:

  • Personal blogs
  • News feeds
  • Photo journals
  • Updates and changelogs

Code Syntax Highlighting

Hugo supports syntax highlighting out of the box. Let’s look at a simple Go example since Hugo is built in Go.

package main

import "fmt"

func main() {
    fmt.Println("Hello, Continuous World!")
}

The design of this theme ensures that code blocks are clearly distinct from the text, using a subtle background color and a monospaced font.
